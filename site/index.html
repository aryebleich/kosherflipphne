KosherFlip

Filtered, kosher Android for flip phones. Install it right here on this phone: no computer, no QR code.

⬇ Download KosherGuard
  1. Press Download KosherGuard. If the phone warns about the file, choose Download anyway.
  2. Open the downloaded file. If asked, allow this browser to install unknown apps, then press Back and open the file again.
  3. Press Install, then Open.
  4. KosherGuard shows a short checklist. Do each step; it installs the other KosherFlip apps for you.

No internet on this phone? Ask someone with a KosherFlip phone to use KosherGuard → Share KosherFlip and send it to you with Bluetooth or Nearby Share.
