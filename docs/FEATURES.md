# Features and comparison

What popular kosher phones offer (from public product listings and support
pages, Nov 2026) and how KosherFlip covers it.

| Feature (seen on) | KosherFlip |
|---|---|
| Flip form factor chosen with rabbinic advice (Fig) | Runs on flip phones; keypad-first UI everywhere |
| Talk-only model with auto text reply; verification codes still arrive (Pom, Wonder talk-only) | **Talk-only mode**: messaging hidden, one polite auto-reply per sender per day, verification codes shown as a notification |
| Closed, curated app set / no outside apps (Fig, Mind) | Only approved apps visible; installs blocked unless the admin opens them; **Request an app** from the app list |
| Can't sideload from a computer (Mind) | USB file transfer, Bluetooth sharing, SD card and unknown sources blocked; optional USB-debugging lock |
| Video blocked except own camera videos (Fig) | Video sites blocked by DNS, video removed in the browser; camera stays usable (can be turned off) |
| Waze / GPS (Mind) | Google Maps and Waze allowed by default |
| Calls, texts, contacts, notes, reminders, calendar, alarm (Mind) | All standard Android apps on the allow list |
| Budget app (Mind) | Allow any budgeting app from the list (or request one) |
| Curated music player (Fig) | Allow a kosher music app; MP3 downloads allowed in the browser |
| Voice messaging, conference calls (Pom) | Provided by the phone's dialer/messaging apps |
| Yiddish T9 keyboard (Pom) | **KosherKeys**: English / Hebrew / Yiddish multi-tap T9, default on keypad phones |
| Voice-to-text (Pom) | The phone's own voice typing (Google) keeps working if allowed |
| Kosher smartphone: useful apps work, distracting content removed (Wonder, filtered smartphones) | Profiles + categories + screen filter + filtered browser |
| Filtered web with whitelist & categories (filter providers) | Standard / strict modes, 14 categories, always-allowed and blocked lists, requests & approvals |
| Software updates through Settings (Mind) | KosherGuard → *Install / update KosherFlip apps* (from GitHub releases); ROM: reflash |

**Extra in KosherFlip**

- Screen filter that reads every app's screen (and notifications), on the phone.
- Free AI assistant with strict safety settings and filtered answers.
- Shabbos & Yom Tov mode (auto by location), Hebrew date and zmanim on the home screen.
- Insights, suggestions and a request/approve flow for the supervisor.
- Ad & tracker blocking and a DNS cache: filtered browsing that feels faster, not slower.
- Open source: the community can review exactly what is filtered.

## Roadmap

- Predictive (dictionary) T9 for Hebrew/Yiddish.
- On-device image classifier for the browser and screen filter.
- Remote admin (approve requests from the supervisor's phone).
- Over-the-air ROM updates.
- Curated "kosher app store" catalog inside KosherGuard.
